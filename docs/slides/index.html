Core loop

Group DRAFT to RUNNING. One cycle at a time.

open → bid (if khui) → close → calculate → pay in → payout → settle

  • Winner share pays 0 that cycle, then becomes Hoi Chet
  • Dead shares pay full base amount C
  • Last bidding cycle: B = 0, no auction

Default formulas

BIDDING_CLASSIC (Hoi khui)

grossPot = D*C + (A-1)*(C-B)

netPayout = grossPot - T

FIXED_EQUAL (Hoi deu)

grossPot = (N-1)*C

Fixture A: N=10, C=1,000,000, T=100,000, cycle1 B=200,000 → net 7,100,000.

Custom formula rules

  • Host edits parameters on a system preset. That is the product.
  • Owner template = saved parameters (mau hoi), no new algebra.
  • New calculator only via code + fixtures, never eval / JS / Excel.
  • Must keep winnerPay = 0, integer minor units, last cycle B = 0.
  • RUNNING groups freeze preset + engineVersion.

Multi-currency

  • Choose currency per group. Owner default VND.
  • Store bigint minor units. VND exponent 0, USD/THB 2.
  • Every money row and every report carries currency + exponent.
  • No FX. Host profit is grouped by currency, never summed across codes.
  • host_fee_minor vs host_fee_bps — percent is not money.

Schema (money)

currencies(code, exponent, symbol)

groups.currency FK, frozen at START. All group money is minor units of that code.

Copied onto cycles, bids, ledger_entries, payments.

JSON: { currency, amountMinor, exponent, symbol }
